About Me

Full-Stack Engineer | Backend Specialist | Architectural Thinker

A dedicated and experienced Full-Stack Developer with a strong foundation in backend engineering using Laravel. I specialize in building maintainable, scalable, and high-performance web applications from the ground up. My passion lies in solving complex problems with clean code and robust architectural patterns.

What I bring to your team:

  • 🚀 End-to-End Development: Expertly crafting applications from database design to a polished user interface, combining a powerful Laravel backend with an interactive React.js frontend using Inertia.js.
  • 📦 Advanced Backend Architecture: Designing scalable systems using Design Patterns like the Service, Repository, and Observer patterns. I build for the future by processing background tasks efficiently with Laravel Queues.
  • ⚛️ Modern Frontend Experience: Building responsive, single-page application experiences with React.js, managing complex state, and integrating seamlessly with backend APIs.
  • 🐳 DevOps & Containerization: Containerizing applications with Docker for consistent development and production environments, and setting up CI/CD pipelines with GitHub Actions for automated, zero-downtime deployments.

I thrive in collaborative environments and I'm always eager to learn and implement new technologies. Let's build something amazing together!
